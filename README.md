## What is it?

The shared hub of the **Drama Director** module family. Adds the sidebar button and unifies all installed Drama Director modules under one panel. Also checks for new releases of every family module and shows a one-click update badge when a newer version is available.

This module is **required** by every other Drama Director module. Install it first.

## Install in Foundry VTT

1. Open Foundry, go to **Add-on Modules** → **Install Module**.
2. Paste the **manifest URL** into the *Manifest URL* field at the bottom:
   ```
   https://github.com/phoenix1cold/drama-director-hub/releases/latest/download/module.json
   ```
3. Click **Install**. Then install whichever family modules you need from the table above using each repository's `releases/latest/download/module.json` URL.

### Manual install (offline)

Download `module.zip` from the [latest release](https://github.com/phoenix1cold/drama-director-hub/releases/latest) and extract it into your Foundry user-data folder at:

```
<FoundryUserData>/Data/modules/drama-director-hub/
```

The extracted folder must contain `module.json` at its root.
